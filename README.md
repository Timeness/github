  GitView
</h1>

**GitView is a browser-based GitHub repository explorer and management workspace. It lets you browse repository files and folders, preview code and common file formats and view repository details in one place.**

**When connected to GitHub, you can create a fork or independent copy, manage dependency update pull requests and perform repository or file actions.**
